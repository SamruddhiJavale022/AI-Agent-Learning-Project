# ADR 1: Selection of Tech Stack for Basic AI Agent

## Status

Accepted

## Context

We are building a basic AI Agent as part of the AI-Augmented Workflow course.

The agent will accept user input and use an AI model to generate a response.

The technology should be simple, beginner-friendly, and suitable for AI-assisted coding.

## Decision

We selected the following technologies:

- **Python** – Main programming language
- **OpenAI API** – AI model integration
- **Git** – Version control
- **GitHub** – Project hosting and portfolio
- **VS Code** – Code editor

Ollama can be used as an open-source alternative to the OpenAI API.

## Consequences

### Advantages

- Python is easy to learn.
- OpenAI API provides simple AI integration.
- Git and GitHub help track project changes.
- AI coding tools can help generate and explain Python code.
- The technologies have good documentation.

### Disadvantages

- OpenAI API requires an API key.
- API usage may have costs depending on the service and account.
- Ollama may require more computer resources when running local models.
- AI-generated code must be checked and tested.

## AI-Assisted Coding Compatibility

This technology stack works well with AI-assisted coding tools.

AI tools can help generate code, explain errors, and suggest improvements. However, the generated code will be reviewed and tested by the student before use.

## Conclusion

Python with the OpenAI API is selected as the primary technology stack because it is simple and suitable for developing a basic AI Agent.
