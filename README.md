# AI Agent Learning Project

## Project Overview

This project is a basic AI Agent developed as part of the AI-Augmented Workflow course.

The AI Agent uses Python and an AI model to understand user input and generate a response.

## Technologies Used

- Python
- OpenAI API
- Git
- GitHub

The main objective of this project is to understand the basic working of an AI Agent and learn how AI tools can be used during software development.
